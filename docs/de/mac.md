# Tor Browser auf macOS

[← Zurück zur Übersicht](../../README.de.md)

**Voraussetzung:** macOS 10.15 (Catalina) oder neuer.

## Installation

1. Öffne in Safari oder einem anderen Browser die offizielle Downloadseite: [torproject.org/download](https://www.torproject.org/download/)
2. Klicke auf **Download for macOS**. Es wird eine `.dmg`-Datei heruntergeladen.
3. *(Empfohlen)* Prüfe die Signatur der Datei. Die Anleitung dazu steht beim Tor-Projekt: [Signatur prüfen](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Doppelklicke auf die `.dmg`-Datei.
5. Ziehe **Tor Browser** in den Ordner **Programme** (Applications).
6. Werfe das `.dmg` danach im Finder aus.

## Erster Start

1. Öffne **Tor Browser** im Ordner Programme oder über Spotlight (Cmd + Leertaste, "Tor" eingeben).
2. Falls macOS fragt, ob du die App öffnen willst: mit **Öffnen** bestätigen.
3. Klicke im ersten Fenster auf **Connect** und warte, bis die Verbindung steht.
4. Öffne [check.torproject.org](https://check.torproject.org). Dort muss **"Congratulations"** stehen.

## Sicherheitsstufe einstellen

1. Klicke auf das **Schild-Symbol** neben der Adresszeile.
2. Klicke auf **Settings**.
3. Klicke auf **Change** und wähle **Safer** oder **Safest**.
4. Klicke auf **Save and restart**.

## Deinstallation

Ziehe **Tor Browser** aus dem Ordner Programme in den Papierkorb.
