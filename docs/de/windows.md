# Tor Browser auf Windows

[← Zurück zur Übersicht](../../README.de.md)

**Voraussetzung:** Windows 10 oder Windows 11.

## Installation

1. Öffne in deinem normalen Browser (Edge, Chrome, Firefox) die offizielle Downloadseite: [torproject.org/download](https://www.torproject.org/download/)
2. Klicke auf **Download for Windows**. Es wird eine `.exe`-Datei heruntergeladen.
3. *(Empfohlen)* Prüfe die Signatur der Datei. Die Anleitung dazu steht beim Tor-Projekt: [Signatur prüfen](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Doppelklicke auf die heruntergeladene `.exe`-Datei.
5. Wähle die Sprache und folge dem Installationsassistenten.
6. Der Installer legt standardmässig eine Verknüpfung auf dem Desktop an.

## Erster Start

1. Starte **Tor Browser** über die Desktop-Verknüpfung oder das Startmenü.
2. Klicke im ersten Fenster auf **Connect**.
3. Warte, bis die Verbindung steht.
4. Öffne [check.torproject.org](https://check.torproject.org). Dort muss **"Congratulations"** stehen.

## Sicherheitsstufe einstellen

1. Klicke auf das **Schild-Symbol** neben der Adresszeile.
2. Klicke auf **Settings**.
3. Klicke auf **Change** und wähle **Safer** oder **Safest**.
4. Klicke auf **Save and restart**.

## Deinstallation

Einstellungen → Apps → Installierte Apps → **Tor Browser** → Deinstallieren.
