# Tor Browser on Windows

[← Back to overview](../../README.md)

**Requirement:** Windows 10 or Windows 11.

## Installation

1. In your normal browser (Edge, Chrome, Firefox), open the official download page: [torproject.org/download](https://www.torproject.org/download/)
2. Click **Download for Windows**. An `.exe` file is downloaded.
3. *(Recommended)* Verify the file's signature. The Tor Project explains how: [Verify the signature](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Double-click the downloaded `.exe` file.
5. Choose your language and follow the installation wizard.
6. By default, the installer creates a shortcut on your desktop.

## First start

1. Start **Tor Browser** from the desktop shortcut or the Start menu.
2. Click **Connect** in the first window.
3. Wait until the connection is established.
4. Open [check.torproject.org](https://check.torproject.org). It must say **"Congratulations"**.

## Set the security level

1. Click the **shield icon** next to the address bar.
2. Click **Settings**.
3. Click **Change** and choose **Safer** or **Safest**.
4. Click **Save and restart**.

## Uninstall

Settings → Apps → Installed apps → **Tor Browser** → Uninstall.
