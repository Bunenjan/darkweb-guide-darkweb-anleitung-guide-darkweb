# First Steps on the Dark Web

[← Back to overview](../../README.md)

**Requirement:** Tor Browser (or Onion Browser on iPhone) is installed. If not, first follow the guide for your device in the [overview](../../README.md).

## 1. Connect and check

1. Start Tor Browser.
2. Tap or click **Connect** and wait until the connection is established.
3. Open [check.torproject.org](https://check.torproject.org). If it says **"Congratulations"**, everything goes through Tor.
4. Set the security level to **Safer** or **Safest** (shield icon next to the address bar).

## 2. Open your first .onion site

The safest way is through the normal website of a well-known service. You do not have to type a long address, and you will not end up on a fake copy.

1. In Tor Browser, enter a normal address, for example `duckduckgo.com` or `proton.me`.
2. If the service has an official .onion version, an **".onion available"** button appears on the right of the address bar.
3. Click it.
4. The address now ends in **`.onion`**. You are on the dark web.

## 3. Find more safe .onion sites

The best source is the **[Real-World Onion Sites](https://github.com/alecmuffett/real-world-onion-sites)** list. It only contains official .onion addresses of large, reputable websites and organisations, each with a source. The maintainer deliberately excludes sites with drugs, nudity, exploitation or other sketchy content.

Good sites to start with (all on the list):

| Site | What it is |
| --- | --- |
| DuckDuckGo | Search engine |
| Proton Mail | Encrypted email |
| ProPublica | Investigative journalism |
| Tor Project | Site of the Tor developers |
| Debian, Whonix | Linux projects |
| Riseup | Services for activists, with its own directory of .onion sites |

How to do it:

1. Open the list in your normal browser.
2. Copy the address of the site you want.
3. Paste it into the address bar of Tor Browser.

Real .onion addresses are 56 characters long and end in `.onion`. Short 16-character addresses are old versions and no longer work.

## 4. What to avoid

- **No addresses from TikTok, Discord, YouTube comments or "dark web link lists".** They contain many scam sites and fake copies of well-known sites.
- **Do not download anything** or open files.
- **No real data:** no name, no email, no passwords, no usernames you use elsewhere.
- **Do not buy anything.** Most shops are scams, and much of it is illegal.
- If a site looks strange or shows something illegal: **close it immediately**, do not click further.

## 5. Checklist before every visit

- [ ] Own device, private network (not work, not school)
- [ ] Tor Browser is up to date
- [ ] check.torproject.org shows "Congratulations"
- [ ] Security level Safer or Safest
- [ ] Clear goal: which site and why
- [ ] Close Tor Browser completely afterwards
