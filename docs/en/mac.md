# Tor Browser on macOS

[← Back to overview](../../README.md)

**Requirement:** macOS 10.15 (Catalina) or later.

## Installation

1. In Safari or another browser, open the official download page: [torproject.org/download](https://www.torproject.org/download/)
2. Click **Download for macOS**. A `.dmg` file is downloaded.
3. *(Recommended)* Verify the file's signature. The Tor Project explains how: [Verify the signature](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Double-click the `.dmg` file.
5. Drag **Tor Browser** into the **Applications** folder.
6. Eject the `.dmg` in Finder afterwards.

## First start

1. Open **Tor Browser** from the Applications folder or via Spotlight (Cmd + Space, type "Tor").
2. If macOS asks whether you want to open the app, confirm with **Open**.
3. Click **Connect** in the first window and wait until the connection is established.
4. Open [check.torproject.org](https://check.torproject.org). It must say **"Congratulations"**.

## Set the security level

1. Click the **shield icon** next to the address bar.
2. Click **Settings**.
3. Click **Change** and choose **Safer** or **Safest**.
4. Click **Save and restart**.

## Uninstall

Drag **Tor Browser** from the Applications folder to the Trash.
