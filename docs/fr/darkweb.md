# Premiers pas sur le dark web

[← Retour à l'aperçu](../../README.fr.md)

**Prérequis :** le Tor Browser (ou Onion Browser sur iPhone) est installé. Sinon, suis d'abord le guide pour ton appareil dans l'[aperçu](../../README.fr.md).

## 1. Se connecter et vérifier

1. Lance le Tor Browser.
2. Appuie ou clique sur **Connect** et attends que la connexion soit établie.
3. Ouvre [check.torproject.org](https://check.torproject.org). Si la page affiche **« Congratulations »**, tout passe par Tor.
4. Règle le niveau de sécurité sur **Safer** ou **Safest** (icône du bouclier à côté de la barre d'adresse).

## 2. Ouvrir ton premier site .onion

Le moyen le plus sûr passe par le site normal d'un service connu. Tu n'as pas besoin de taper une longue adresse, et tu ne tomberas pas sur une fausse copie.

1. Dans le Tor Browser, saisis une adresse normale, par exemple `duckduckgo.com` ou `proton.me`.
2. Si le service a une version .onion officielle, un bouton **« .onion available »** apparaît à droite de la barre d'adresse.
3. Clique dessus.
4. L'adresse se termine maintenant par **`.onion`**. Tu es sur le dark web.

## 3. Trouver d'autres sites .onion sûrs

La meilleure source est la liste **[Real-World Onion Sites](https://github.com/alecmuffett/real-world-onion-sites)**. Elle ne contient que des adresses .onion officielles de grands sites et organisations sérieux, chacune avec sa source. Le responsable exclut volontairement les sites de drogue, de nudité, d'exploitation ou au contenu douteux.

Bons sites pour commencer (tous sur la liste) :

| Site | Ce que c'est |
| --- | --- |
| DuckDuckGo | Moteur de recherche |
| Proton Mail | E-mail chiffré |
| ProPublica | Journalisme d'investigation |
| Tor Project | Site des développeurs de Tor |
| Debian, Whonix | Projets Linux |
| Riseup | Services pour activistes, avec son propre répertoire de sites .onion |

Comment faire :

1. Ouvre la liste dans ton navigateur habituel.
2. Copie l'adresse du site voulu.
3. Colle-la dans la barre d'adresse du Tor Browser.

Les vraies adresses .onion font 56 caractères et se terminent par `.onion`. Les adresses courtes de 16 caractères sont d'anciennes versions et ne fonctionnent plus.

## 4. Ce qu'il faut éviter

- **Pas d'adresses venant de TikTok, Discord, commentaires YouTube ou « listes de liens du dark web ».** Elles contiennent beaucoup de sites d'arnaque et de fausses copies de sites connus.
- **Ne rien télécharger** et n'ouvrir aucun fichier.
- **Pas de vraies données :** pas de nom, pas d'e-mail, pas de mots de passe, pas de pseudos que tu utilises ailleurs.
- **Ne rien acheter.** La plupart des boutiques sont des arnaques, et une grande partie est illégale.
- Si un site semble bizarre ou montre quelque chose d'illégal : **ferme-le immédiatement**, ne clique pas plus loin.

## 5. Checklist avant chaque visite

- [ ] Propre appareil, réseau privé (pas le travail, pas l'école)
- [ ] Tor Browser à jour
- [ ] check.torproject.org affiche « Congratulations »
- [ ] Niveau de sécurité Safer ou Safest
- [ ] Objectif clair : quel site et pourquoi
- [ ] Fermer complètement le Tor Browser ensuite
