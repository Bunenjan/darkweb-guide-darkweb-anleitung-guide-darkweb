# Tor sur iPhone et iPad

[← Retour à l'aperçu](../../README.fr.md)

**Important :** Il n'existe **pas de Tor Browser officiel** pour iPhone et iPad. Le Tor Project recommande à la place l'appli **Onion Browser**. Elle est open source, utilise le réseau Tor et est développée par une personne qui travaille en étroite collaboration avec le Tor Project.

**Prérequis :** iOS 15 ou plus récent.

## Limitation

Apple exige que tous les navigateurs sur iPhone utilisent une technologie appelée WebKit. C'est pourquoi Onion Browser **n'a pas les mêmes protections** que le Tor Browser sur ordinateur ou sur Android. L'EFF déconseille de l'utiliser pour une navigation très sensible. Si tu as besoin de plus de protection, utilise un ordinateur.

## Installation

1. Ouvre l'**App Store**.
2. Cherche **Onion Browser**.
3. Vérifie le vendeur : l'appli est de **Mike Tigas**.
4. Appuie sur **Obtenir**.

> **Attention :** L'App Store contient beaucoup d'applis avec « Tor » dans le nom, souvent payantes ou avec un VPN intégré. Seul **Onion Browser** est recommandé par le Tor Project.

## Premier démarrage

1. Ouvre **Onion Browser**.
2. Suis les étapes à l'écran et connecte-toi au réseau Tor.
3. Ouvre [check.torproject.org](https://check.torproject.org). La page doit afficher **« Congratulations »**.

## Sécurité

- Cherche les options de sécurité dans les réglages de l'appli et choisis le niveau le plus strict avec lequel tes sites fonctionnent encore.
- Les règles de comportement de l'[aperçu](../../README.fr.md#règles-de-comportement) s'appliquent aussi ici.

## Optionnel : Orbot

Sur iOS, le Tor Project recommande aussi l'appli **Orbot**. Elle permet à d'autres applis de passer par Tor. Pour débuter, Onion Browser suffit.

## Désinstallation

Appuie longuement sur l'icône de l'appli → **Supprimer l'app** → **Supprimer l'app**.
