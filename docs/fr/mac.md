# Tor Browser sur macOS

[← Retour à l'aperçu](../../README.fr.md)

**Prérequis :** macOS 10.15 (Catalina) ou plus récent.

## Installation

1. Dans Safari ou un autre navigateur, ouvre la page de téléchargement officielle : [torproject.org/download](https://www.torproject.org/download/)
2. Clique sur **Download for macOS**. Un fichier `.dmg` est téléchargé.
3. *(Recommandé)* Vérifie la signature du fichier. Le Tor Project explique comment : [Vérifier la signature](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Double-clique sur le fichier `.dmg`.
5. Fais glisser **Tor Browser** dans le dossier **Applications**.
6. Éjecte ensuite le `.dmg` dans le Finder.

## Premier démarrage

1. Ouvre **Tor Browser** depuis le dossier Applications ou via Spotlight (Cmd + Espace, tape « Tor »).
2. Si macOS demande si tu veux ouvrir l'app, confirme avec **Ouvrir**.
3. Clique sur **Connect** dans la première fenêtre et attends que la connexion soit établie.
4. Ouvre [check.torproject.org](https://check.torproject.org). La page doit afficher **« Congratulations »**.

## Régler le niveau de sécurité

1. Clique sur l'**icône du bouclier** à côté de la barre d'adresse.
2. Clique sur **Settings**.
3. Clique sur **Change** et choisis **Safer** ou **Safest**.
4. Clique sur **Save and restart**.

## Désinstallation

Fais glisser **Tor Browser** du dossier Applications vers la corbeille.
