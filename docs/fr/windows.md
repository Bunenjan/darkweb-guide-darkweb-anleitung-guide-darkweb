# Tor Browser sur Windows

[← Retour à l'aperçu](../../README.fr.md)

**Prérequis :** Windows 10 ou Windows 11.

## Installation

1. Dans ton navigateur habituel (Edge, Chrome, Firefox), ouvre la page de téléchargement officielle : [torproject.org/download](https://www.torproject.org/download/)
2. Clique sur **Download for Windows**. Un fichier `.exe` est téléchargé.
3. *(Recommandé)* Vérifie la signature du fichier. Le Tor Project explique comment : [Vérifier la signature](https://support.torproject.org/tbb/how-to-verify-signature/)
4. Double-clique sur le fichier `.exe` téléchargé.
5. Choisis la langue et suis l'assistant d'installation.
6. Par défaut, l'installateur crée un raccourci sur le bureau.

## Premier démarrage

1. Lance **Tor Browser** depuis le raccourci du bureau ou le menu Démarrer.
2. Clique sur **Connect** dans la première fenêtre.
3. Attends que la connexion soit établie.
4. Ouvre [check.torproject.org](https://check.torproject.org). La page doit afficher **« Congratulations »**.

## Régler le niveau de sécurité

1. Clique sur l'**icône du bouclier** à côté de la barre d'adresse.
2. Clique sur **Settings**.
3. Clique sur **Change** et choisis **Safer** ou **Safest**.
4. Clique sur **Save and restart**.

## Désinstallation

Paramètres → Applications → Applications installées → **Tor Browser** → Désinstaller.
